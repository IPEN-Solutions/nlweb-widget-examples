# AI Digital Transformation Agency starter profile

Synthetic starter content for an agency that provides AI-enabled digital transformation strategy, consultancy, implementation and enablement services.

Replace all example names, URLs, descriptions, industries, people, case studies and service claims with the domain owner's authoritative content before production.

Run from the project root:

```powershell
uv run fastapi-nlweb demo validate --profile ai-digital-transformation-agency
```

Then copy/customize the files into your application's content source directory and ingest them with your selected retrieval store.

The profile uses Schema.org/JSON-LD types and ordinary domain terms; `AI-Reach Marketing` or similar emerging terminology is intentionally represented as a business-defined service name rather than a new Schema.org type.
