# Examples changelog

## 0.1.8 — approved release (changes from 0.1.7)

- Add a local-first English/Persian retrieval benchmark with a scenario catalogue, registered corpus/query sources, isolated SQLite + sqlite-vec results, per-run reports, and JSON/Markdown comparative matrices.
- Provide CPU-first Sentence Transformers and opt-in local Ollama benchmark paths, including compatible cross-embedder comparisons; keep hosted inference and MTEB public-task downloads out of the default workflow.
- Keep MTEB and Nomic MegaBlocks GPU optimization disabled by default; document explicit opt-in, model-code trust, hardware, native-toolchain, and memory prerequisites.
- Add scenario-oriented VS Code tasks and regression coverage while preserving benchmark ranking behavior and the Widget runtime contract.
- Retain independent Scrapy + Ollama, Scrapy + Hugging Face Transformers, custom extraction, remote-storage, and CouchDB examples, including separate extraction artifacts and provenance.

## 0.1.7 — previous approved release

The approved reference suite established the framework integrations, provider examples, source-ingestion patterns, and visibility demonstrations carried forward into 0.1.8.
