# Framework comparison

| Framework | Boundary | Best reason to study it |
|---|---|---|
| FastAPI | ASGI | Primary modern Python API example |
| Flask | WSGI | Conventional lightweight web application |
| Django | Django URL/application stack | Larger integrated application framework |
| Starlette | ASGI | Minimal ASGI framework |
| stdlib | `http.server` | Lowest-level protocol reference |

The comparison is about integration mechanics, not framework quality or recommendation.
