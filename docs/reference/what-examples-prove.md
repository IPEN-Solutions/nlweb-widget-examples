# What the examples prove

## They demonstrate

- framework-specific integration with a framework-neutral widget;
- an observable HTTP protocol boundary;
- separation between application domain data and AI-facing protocol handling;
- a path for an independent AI consumer to reach the application;
- deterministic tests that do not require live LLM access.

## They do not demonstrate

- automatic indexing by every AI search product;
- guaranteed retrieval for every query;
- a specific LLM's answer quality;
- production authentication, authorization, rate limiting or deployment hardening;
- unverified provider compatibility in upstream AskAgent.

The examples are reference implementations, not production deployment claims.
