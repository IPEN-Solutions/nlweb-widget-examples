# Django

Path: `examples/django_services/`

The Django example shows how the widget can sit alongside Django URL configuration and application logic.

## Consumer takeaway

A Django application does not need to become an AI-specific application. Treat the widget as an integration layer and keep existing domain services and persistence authoritative.

The scenario data is in `examples/django_services/data.json` and demonstrates digital transformation consulting, AI readiness, process automation and multi-location service operations.
