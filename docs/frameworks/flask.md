# Flask

Path: `examples/flask_marketing/`

The Flask example demonstrates the same protocol boundary through a WSGI application.

## Consumer takeaway

The framework changes the adapter mechanism, not the conceptual architecture. Your Flask application remains responsible for its domain content while the widget supplies the NLWeb-facing surface.

The scenario data is in `examples/flask_marketing/data.json` and demonstrates AI-reach marketing, organic inbound marketing, MarTech automation and structured content/entity optimization.
