# Starlette

Path: `examples/starlette_catalog/`

Starlette provides a deliberately lightweight ASGI reference.

## Consumer takeaway

This example is useful for verifying that the architecture is not inherently coupled to FastAPI. The core protocol behavior remains independent of the ASGI framework.

The scenario data is in `examples/starlette_catalog/data.json` and demonstrates an enterprise AI assistant, knowledge hub and documentation suite.
